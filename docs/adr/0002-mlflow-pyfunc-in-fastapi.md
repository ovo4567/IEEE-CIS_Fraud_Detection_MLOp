# Serve via MLflow pyfunc in FastAPI

One model artifact serves both the real-time API and the batch scorer: `train.py` saves the model as an MLflow `pyfunc` (`mlflow.pyfunc.save_model` with a custom `PythonModel`), wrapping the full 218-feature transform, the LightGBM booster, and the operating threshold; FastAPI and the batch CLI load the same pyfunc. Rejected: a raw LightGBM booster with a hand-rolled transform wrapper (duplicates the transform and risks train/serve drift), a plain sklearn joblib (no registry lineage), and `mlflow.lightgbm.log_model` alone (its pyfunc returns class labels, not fraud probabilities, and cannot carry the transform). Consequence: MLflow becomes the single artifact source of truth, and the feature contract is enforced inside the pyfunc wrapper.
